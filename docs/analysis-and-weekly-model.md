# 模型增强周报与论文总体分析

## 使用

1. 更新代码后重启 API 与 worker，刷新前端。不需要新增依赖或覆盖 `.env`、模型配置、数据库。
2. 主题订阅：选择 Agent 强化学习 / 大模型后训练，默认近 730 天、CCF A 核实优先、无匹配时 arXiv 回退。
3. 需要模型周报时，主动勾选“模型增强周报”，设置每期评估候选上限（1–10，默认 5）。定时和手动生成均遵守此配置；原有订阅默认规则模式。
4. 论文详情：先读取全文，核对解析警告，再打开“总体分析”生成。任务状态来自后端 SSE。完成后下载 Markdown，或点击“按翻译模板生成分析 PDF”。

## 周报机制

关键词初排后，在上限内对候选按**当前订阅主题**评估，而非使用全部兴趣的最高分。保留关键词分、语义分、证据和未核实项；语义成功的项使用语义分，否则使用关键词分，再加个人反馈调整并限制为 0–100。CCF A 核实优先级保持，其后才按相关性排序。混合评分不代表经过概率校准的论文质量。

相同论文版本、摘要、主题、模型地址/名称和语义 Skill 版本命中缓存。缓存候选计入评估上限，但不计模型请求次数。每次请求前保存尝试记录，成功/失败后写检查点。网络结果不确定或进程中断的项本期降级，**不自动重复付费请求**；下期或用户修改订阅配置后是独立的新任务，可能重新调用失败项。

无密钥、任务创建后服务配置变化、解析/证据校验失败或超出上限均明确降级。模型启用只影响用户主动保存的新配置，不会代替用户开启订阅或改变历史周报。

## 总体分析

注册 `paper_analysis` 和 `analysis_pdf` 两个实际可执行 Skill。研究问题、方法、创新、实验、局限、可借鉴研究思路均带原文块证据；分析建议与作者陈述明确区分。全文分块及综合步骤分别保存检查点。只分析可读取内容，缺页和未分析块不猜补。

PDF 与翻译共用黑色宋体单栏/双栏模板，依据原文栏式自动选择。分析和编译是独立任务，编译失败不重做模型分析。无密钥时不能新生成分析，但可排版已完成分析。文件名：`原论文名称总体分析.md/pdf`。

报告格式统一不等于逐页复刻原文；总体分析是摘要式研究报告，页数由内容决定。证据原句在页面和 Markdown 可核对，中文 PDF 保留证据位置；原文图片仍保留在原件与译文中，不将图片无依据地附加到分析报告。
