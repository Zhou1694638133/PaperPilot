# 推荐评估说明

阶段一验证的是证据可追溯性、规则实现与数据真实性，尚未进行研究者标注的相关性评估。自动化测试中的固定摘要与预期结果是回归夹具，不应称为人工标注的推荐基准。

下一步应固定研究兴趣、日期窗口、来源与候选集合，由研究者标注不相关/部分相关/高度相关，并记录判断依据。至少对标题、摘要和全文证据分别标记覆盖范围，避免把“系统只看到摘要”误判成已核实全文。建议从 20–50 篇开始，并抽样做第二人复核。

之后可报告 Precision@K、nDCG@K、重复率、主题覆盖、证据正确率，以及实际延迟和模型 token 使用量。当前未运行这些指标，不填占位成绩。规则权重 75% 研究兴趣命中 + 25% 命中词标题覆盖只是可编辑的初始设计，没有被宣称为最优参数。
