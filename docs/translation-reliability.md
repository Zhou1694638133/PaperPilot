# 翻译预检与恢复

全文工作台在全文解析完成后展示“整篇翻译预检”。预检无须模型，列出正文、标识符、结构保护、需核对的数量及位置。任务执行时再次预检，避免绕过页面直接提交而跳过检查。

单块输出校验失败时，失败原因保存在后端，其他独立块继续。任务结束显示“部分完成”，任务中心和全文工作台均可查看未完成块。双语对照未完成处为空并显示原因；完整译版下载须全部完成。

点击“重试未完成部分”可复用已成功段落。网络或配额错误不会自动连续请求后续段落；结果不确定时仍需确认计费风险。预检阻塞的来源问题不能通过重试猜补，需要先核对原文。

无新增依赖，无数据库迁移，已有任务和译文保留。更新后在 PyCharm 重启 `uvicorn` 和 `app.worker`，刷新页面，旧失败任务可直接从检查点继续。
