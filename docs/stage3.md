# 阶段三：主题订阅、站内周报与推荐反馈

## 使用方法

1. 重启 API、独立 worker 与前端。沿用 scripts/start.ps1 api / worker / web（以 start.ps1 的参数为准），不需要安装新依赖。
2. 侧栏“主题订阅”：填写名称、研究方向，选 Agent 强化学习或大模型后训练预设；生成并编辑英文检索式。
3. 选择 CCF A 核实优先（默认，无结果回退 arXiv）或 arXiv；首次公开日期默认近 730 天。
4. 设置北京时间的星期与小时、每期数量（1–30），可添加包含/排除词。必须主动勾选开启；默认保存为暂停。
5. 点击“生成本期周报”可手动验证，无需开启每周计划。查看任务中心真实进度，周报成功后在“站内周报”阅读及下载 Markdown。
6. 在周报或在线论文卡片中展开“推荐反馈”，填写判断与可选原因；侧栏“推荐反馈”可撤回。阅读、收藏、摘要分析、全文翻译仍在原论文详情。

## 持久性与运行边界

- 仅本地单用户、站内内容；不发邮件，不自动调用模型。无密钥时真实检索、周报与反馈可用，精读和翻译继续明确标注未配置。
- worker 的独立调度线程每 30 秒检查到期计划，长任务执行期间也可入队；执行仍为单并发，关闭电脑不会运行。重启后补本周一次，不补所有历史周；不会自动重试本周失败任务。
- 周次按 UTC+8 的周一计算。内容配置修订 + 周次构成幂等键；改名称、时间或暂停/恢复不会重复生成本周报告。
- 同一周重复点击复用已有任务。失败、取消后通过任务中心显式重试；暂停订阅仍可手动生成或重试。
- 暂停阻止未来调度，已排队的计划任务执行前再检查暂停状态；已开始的任务请在任务中心取消。
- 执行使用提交时配置快照。查询结果持久检查点复用；中断恢复由现有租约/heartbeat/SSE 负责。
- 新增 subscriptions、weekly_reports、recommendation_feedback 三张表；不改旧表、不清空文库、不改翻译检查点。
- 每期重新检索指定近年窗口，不只查最近一周。初版最多 50 篇主题候选，再按已有会议适配器补充核验；不是全量文献监控。
- 同 arXiv ID 取最高版本。“新收录”指同订阅此前成功周报未收录的 ID，更新版本不冒充新论文。
- CCF A 覆盖沿用 NeurIPS、ICML、ACL 官方来源与已有证据目录；不是完整 CCF A 索引。Google Scholar 不自动抓取。
- 报告冻结本期分数、论文与来源；阅读页显示当前反馈，原报告顺序和下载快照保留。模型分析和翻译仍由用户主动触发。

## 反馈计算

| 用户反馈 | 效果 |
| --- | --- |
| 与研究相关 | 排序分 +5 |
| 内容过于基础 | 排序分 -5 |
| 希望更多实验依据 | 排序分 -3 |
| 不相关 | 后续发现检索和周报隐藏 |
| 撤回 | 调整归零，取消反馈隐藏 |

保留原始关键词及语义分，不把反馈当作实验事实。发现页按语义分（可用时）或关键词分，加独立反馈调整排序；CCF A 优先级在前；按日期排序时不改变日期顺序。不相关始终过滤。反馈不自动改变研究兴趣，不是在线训练模型；live/demo 隔离，本地上传不参与。

## API

- GET/POST /api/subscriptions：读取/创建；POST 默认 enabled=false、days=730。
- PUT /api/subscriptions/{id}：完整更新配置，内容变更产生新 revision。
- PUT /api/subscriptions/{id}/enabled：原子暂停或启用。
- POST /api/subscriptions/{id}/run：手动提交本期任务，返回 job 与幂等说明。
- GET /api/weekly-reports?limit=20&offset=0：分页状态与未读标记。
- GET /api/weekly-reports/{id}：成功周报；未完成返回 409。
- PUT /api/weekly-reports/{id}/read：标为已读。
- GET /api/jobs/{id}/artifact：周报 Markdown 附件。
- PUT /api/feedback/{paper_id}?mode=live：value= relevant/not_relevant/too_basic/lacks_experiments/none，reason 可选。
- GET /api/feedback?mode=live&limit=20&offset=0：分页历史（撤回项不展示）。

周报 runner 注册为 weekly_digest v1.0.1，实际规范位于 skills/weekly_digest/SKILL.md。

## 阶段三复查修复（2026-10-29）

- 编辑名称或检索内容时保留原到期时间；只有开启/关闭或星期/小时变化才重新安排，防止漏掉已到期计划。
- 创建订阅支持 Idempotency-Key（1–100 字符）。同一键同一输入返回原订阅；不同内容返回 409。前端失败重试沿用原键，成功后为下次创建生成新键。无键请求仍表示新的创建意图。
- 同一订阅、内容 revision、北京时间周次仍只创建一个任务。明确修改内容会产生新 revision，这是新的配置快照，不是重复生成。
- 发现页反馈立即同步排序和隐藏；旧“不感兴趣”按钮统一写入可撤回反馈。明确的相关性/排序反馈可恢复旧版隐藏标记，收藏、笔记、标签、原评分不变。
- 周报页面刷新会重新读取当前报告；历史报告顺序和 Markdown 内容保持冻结，最新反馈用于后续检索。
- 本地前端写入允许 127.0.0.1 / localhost 的 5174 端口；其他非白名单来源继续拒绝。
