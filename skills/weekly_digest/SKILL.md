# 主题订阅周报

版本：1.1.0

应用 runner：backend/app/subscriptions.py:run_digest。注册表：backend/app/skills.py。
本文是规范，不能作为任意代码执行。输入 schema 为 SubscriptionInput，结果继承 SkillResult。
通过 /api/subscriptions/{id}/run 或 worker 的到期调度创建任务；不能使用单篇论文 JobInput 提交。

- 仅用户显式开启后自动按周运行；默认暂停。手动生成无需开启计划。
- 默认首次公开近 730 天，排除未来日期；更新日期和会议年份不能替代首次公开日期。
- Agent 强化学习和大模型后训练使用 research.TRACKS 的聚焦检索式，可由用户编辑；保存实际日期限定表达式。
- 复用正式会议核验与 arXiv 适配器、缓存及跨进程限流。CCF A 优先仅用于有正式证据的记录，未核实保持未知；无符合条件的 CCF A 时使用相关 arXiv 论文。
- 有界检索，不声称覆盖完整 CCF A 或 Google Scholar。周报记录来源状态和警告。
- 普通代码检索、去重和规则排序，默认不调用任何模型。无密钥明确显示未配置，不生成伪造模型解读。
- 只覆盖标题与摘要，保留推荐兴趣、原文证据位置、关键词分、未知项和个人反馈调整。个人反馈不是学术质量事实。
- 同一订阅内容修订、北京时间周一周次只创建一个任务；事务和唯一约束保护并发重复提交。
- 调度固定 UTC+8，启动后仅补本周一次。worker 独立调度线程每 30 秒检查（长任务不阻塞入队，执行仍单并发）；暂停阻止后续调度，并在尚未开始的计划任务执行前校验。
- 普通队列执行；真实阶段通过持久 SSE 事件传达。检索结果写检查点，失败重试复用；主动开启模型增强后计费遵守每期候选上限和逐篇检查点。
- 手动重试是用户主动请求，允许已暂停订阅继续该次任务。执行中的任务通过任务中心取消。
- 周报正文完成且任务成功后才可阅读；列表显示排队、失败等真实状态。下载 Markdown 复用任务产物。
- “新收录”仅表示同订阅历史成功周报未出现该 arXiv ID，不等于本周发表。历史周报内容及顺序固定，当前反馈可查看但不重写原报告。

## 阶段三复查修复（2026-10-29）

- 编辑名称或检索内容时保留原到期时间；只有开启/关闭或星期/小时变化才重新安排，防止漏掉已到期计划。
- 创建订阅支持 Idempotency-Key（1–100 字符）。同一键同一输入返回原订阅；不同内容返回 409。前端失败重试沿用原键，成功后为下次创建生成新键。无键请求仍表示新的创建意图。
- 同一订阅、内容 revision、北京时间周次仍只创建一个任务。明确修改内容会产生新 revision，这是新的配置快照，不是重复生成。
- 发现页反馈立即同步排序和隐藏；旧“不感兴趣”按钮统一写入可撤回反馈。明确的相关性/排序反馈可恢复旧版隐藏标记，收藏、笔记、标签、原评分不变。
- 周报页面刷新会重新读取当前报告；历史报告顺序和 Markdown 内容保持冻结，最新反馈用于后续检索。
- 本地前端写入允许 127.0.0.1 / localhost 的 5174 端口；其他非白名单来源继续拒绝。

## 模型增强（默认关闭）

`model_enabled=false`，`model_limit=5`（1–10）是 SubscriptionInput 可选字段。仅用户保存开启后，runner 通过 weekly_semantic.enrich 直接复用 semantic.run 评估本订阅主题；不会排队等待子任务。关键词分保留作对照；CCF A 优先和首次公开近730天不变。

每个候选调用前写尝试记录，响应后写检查点。相同来源版本、摘要、主题、模型及 prompt 命中持久缓存；超限/无密钥/模型变更/失败项降级关键词。未确认的调用本期不自动重试，原始成功翻译不受影响。缓存候选也计入候选上限，结果分别记录尝试数、成功数和缓存数。

反馈效果对照使用真实用户相关/不相关标签，当前兴趣和模型匹配的语义结果，不加入反馈加分防止标签泄漏。至少30个配对样本后才给已标注池的前10相关比例；必须说明选择偏差，不称作全库准确率。
