# local_source_fetch · 恢复原图与源文件

版本：1.0.0。执行：backend/app/local_source.py，独立 worker，无模型依赖。

输入：JobInput（skill_id=local_source_fetch，paper_id 为已上传本地 PDF）。输出：SkillResult，含来源、document_hash、段落数量和警告。

仅从 PDF 首页读取唯一、带版本的 arXiv 标识，不按文件名猜测。下载固定 HTTPS arXiv 同版本 PDF，逐页文本或整文件 SHA-256 一致后才获取源包。源包沿用现有大小限制、路径和图片验证；失败不替换现有文档。不执行源文件模板，不改原上传文件、收藏及历史译文检查点。

成功后中文 PDF 和双语 PDF 使用已有单/双栏模板及原图；本地原 PDF 决定栏式。后续翻译仅复用同论文、模型、提示词版本、provider、术语表一致且正文逐字相同的检查点；不按相似度复用，不自动调用模型重译。

无法获取源文件或核对失败时明确报错，文字版仅为用户自选备用，不能声称已经保留原图。当前不支持无 arXiv 版本标识的源包关联。


源文件恢复成功表示版本与资源核对通过，不等于翻译或 PDF 编译已经完成。后续排版继续执行命令白名单、缺字和引用校验；不支持的模板语法必须明确报错。已验证 `faLightbulbO` 图标经可信字体包保留，原图不栅格化、不重绘。
