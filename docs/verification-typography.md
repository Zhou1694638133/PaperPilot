# 全站字号与响应式检查

本次只调整 `frontend/src/styles.css`，不改业务逻辑、模型配置、论文数据或翻译检查点。

## 调整内容

原有桌面和手机断点中大量 6–12px 字号改为共享的 rem 字号层级：辅助文字至少 14px、常用界面文字 15px、正文 16px、小标题 18px。保留大标题原有层级；手机端通过换行适配，不再把字体降回 8–12px。

| 区域 | 原字号 | 现字号 |
| --- | --- | --- |
| 品牌副标题 | 8px | 14px |
| 顶部面包屑 | 11px | 15px |
| 左侧研究方向 | 12px | 16px |
| 论文作者 | 12px | 16px |
| 日期、版本等元信息 | 10px | 15px |
| Copilot 标题 | 14px | 18px |
| Copilot 模型状态 | 8px | 14px |
| Copilot 证据段落 | 11–12px | 15px |
| 阅读正文 | 15px | 16px |

同时增加辅助文字对比度；扩展桌面侧栏和 Copilot 可用宽度；品牌副标题、状态行、任务信息、操作按钮允许换行。320px 窄屏的顶部操作行和阅读标签改为按整项换行，避免缩字或把中文按钮拆散。

## 实际验证

- 在前端目录运行 `npm.cmd run build`，包含 TypeScript 检查及 Vite 生产构建。
- 浏览器检查 1920px 桌面下的论文详情、发现论文、我的文库、论文对比、术语表、Skills 工作台、任务中心、研究偏好；渲染中的界面文字最小 14px，没有页面横向溢出或检查到的文本越界。
- 在 390px 和 320px 手机视口检查上述页面、Copilot 抽屉及双语阅读。页面没有横向溢出；原文和译文仍能阅读，原检查点数据未修改。
- 在 1240px 笔记本视口检查发现与详情三栏布局，文字不溢出。
- 检查依据为实际 DOM 计算字号和边界，辅以截图查看；排除隐藏文字与装饰 SVG。文库和对比页面使用当前的空状态，未伪造收藏或对比数据。

没有新增依赖。此变更仅影响在线界面，不重生成论文 PDF。
